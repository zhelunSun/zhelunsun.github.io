# Zhelun Sun's Personal Researcher Website Implementation Plan

本方案旨在为您打造一个2026年专业、前沿、美观且具有动态交互设计的个人主页。

## 1. 2026年前沿技术栈推荐

- **核心框架**: **Next.js 15 (React 19, App Router)**。
- **样式与UI**: **Tailwind CSS v4 + Vanilla CSS**。
- **动效库**: **Framer Motion**。实现极致丝滑的页面滚动、页面过渡以及交互微动效。
- **部署**: **Vercel** 

## 2. 网站模块规划 (根据您的建议调整)

主页布局将侧重于精兵简政，专注于展示能凸显学术与工程深度的核心内容，模块如下：

1. **个人简介 (Personal Bio)**
   首屏重点展示。左侧照片，右侧精简的Bio（包含您在 Intelligent Systems, Remote Sensing 的专注点，尤其是 LLM-based multi-agent system）。

2. **教育背景 (Education)**
   简洁的一行或两行，展示 Tsinghua Ph.D. 与 China Agricultural University B.Sc.。

3. **研究论文 (Publications)**
   按时间/贡献度排序，高亮您的一作论文和关键共著。每一项会附上直接的 PDF/Code/Demo 徽章链接。

4. **精选项目 (Projects)**
   用卡片形式（配合悬浮动效）展示您最具代表性的工作，比如 ExpertsRS 框架的整体架构图和演示。

5. **技术博客 (Tech Blog) - 预留**
   用于存放深度的思考和技术分享记录。可以基于 MDX 编写。

> 这个规划将贯穿我们后续的页面组件设计。
